# Backup locali

Cartella predisposta per future copie di sicurezza. Al 2026-10-02 contiene soltanto questo README: nessun backup è stato creato o verificato e nessuna procedura automatica è attiva.

I contenuti della cartella sono esclusi da Git; questo README resta versionato. La copia originale del PRD è conservata e versionata in [documentazione/archive/](../documentazione/archive/product-original-2026-10-02.md). Git conserva lo storico delle modifiche; questa cartella ospiterà le copie previste dal relativo incarico.

Per ogni futura copia registrare data, contenuti, versione/commit di origine, impronta e prova di ripristino in un [report](../documentazione/templates/report.md). Gestire accessi, conservazione e dati secondo [infrastructure.md](../documentazione/infrastructure.md) e [compliance.md](../documentazione/compliance.md). Non inserire segreti o dati personali nei report.

Una copia sullo stesso disco protegge soltanto dagli errori recuperabili tramite quella copia. Destinazione esterna, frequenza, conservazione e ripristino restano da progettare nell'incarico dedicato.
