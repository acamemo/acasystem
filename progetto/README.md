# Progetto applicativo

Questa cartella ospiterà codice sorgente, test e configurazioni di sviluppo e distribuzione quando richiesti. Al 2026-10-02 contiene soltanto questo README: non sono stati creati un'applicazione, manifest, dipendenze o servizi.

Le istruzioni del repository sono in [AGENTS.md](../AGENTS.md). Prima di iniziare leggere [lo stato e l'incarico attivo](../documentazione/project-status.md#incarichi-e-punto-di-ripresa), [il PRD](../documentazione/funzionalita/product.md) e [le decisioni](../documentazione/decisions/README.md).

La direzione corrente è Home Assistant locale con riferimento React Tunet e fase 1 grafica in ufficio, descritta in [pilot-scope.md](../documentazione/funzionalita/pilot-scope.md). Struttura interna, metodo HA, versioni e integrazione concreta saranno definiti nell'incarico pertinente. Questa cartella contiene ancora solo il README. Documenti e report restano in [documentazione/](../documentazione/README.md); le future copie locali vanno in [backup/](../backup/README.md).
